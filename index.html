AUTHENTICATION PROTOTYPE

Masuk dengan Google

Gunakan akun Gmail yang telah didaftarkan sebagai pengguna uji SIM-BA HGU.
Client ID bukan rahasia. Untuk menghindari penulisan di repository, masukkan langsung di halaman ini; hanya Client ID disimpan di browser ini.
Masukkan Client ID lalu klik “Aktifkan Tombol Login”.
Identitas akun dari ID Token (tampilan lokal)
Belum diverifikasi di server. Data ini hanya hasil pembacaan payload ID Token di browser dan bukan bukti akses ke backend SIM-BA HGU.
Tidak ada token yang dikirim ke Google Sheets, Google Apps Script, GitHub, atau server lain oleh halaman ini. Token tidak disimpan di browser maupun ditampilkan dalam log.
